Dial sections

Each section is one Bézier curve, and the sections join end to start in order. Values are recorded as you go and kept in this browser.

Drag any dot to edit it. Hollow dots are the Bézier handles and dark dots mark where sections join. The first point only moves up and down, with a dark line joining it to the middle line. The square at the end sits at the same height as the first point, joined to the last endpoint by a dark line. The thin line running across is the middle line, and the dashed lines mark the limit of 1 above and below it.

First point

Move it up or down to add a straight line from the middle line. It can’t move sideways.

Recorded values


  
In your own code, call getDialValues() to get this same data. Length can be any number from 0 up. Length and handle x are measured from the section’s start, and handle x can sit from one length behind the start to two lengths ahead (at least 1 either way). Every y value (First point, End y and the handles) is the height above or below the middle line, from −1 to 1, which keeps the whole curve inside that band.
